# Core 0.20.3 release gate status

**In progress. No 0.20.3 candidate, freeze, tag, or publication is approved.**

The baseline is the published Core 0.20.2 commit
`fb72911ce58173bf3669181d0e2c25eeefeaa58d`. The 0.20.3
[design](../design-core-architecture-freeze-0.20.3.md) defines four phases and
requires explicit release approval after an exact candidate is fixed.

Initial work and open questions are recorded in:

- [Agent readiness](0.20.3-agent-readiness.md).
- [Scoped processing](0.20.3-scoped-processing.md).
- [SQLite scoped-read scaling](0.20.3-scoped-read-scaling.md).
- [Cognitive invariant inventory](0.20.3-invariant-matrix.md).

On 25 November 2026 the release owner approved warm `prepare_context()` p95 below
2.5 seconds separately for memory and SQLite on the existing 1,000-observation
reference fixture, and approved separate original-protocol timing and
independent cognitive-state snapshot audits for 0.20.3. Timing and snapshot
results must remain distinct. The owner also adopted the 50-project,
250-observation-per-project scoped SQLite gate described in
[scaling findings](0.20.3-scoped-read-scaling.md).

The approved protocols and targets still require execution against the exact
candidate or appropriately scoped demonstrably equivalent runtime evidence.
Independent exact-candidate
Bench review, full platform and PostgreSQL CI, artifact validation, final
architecture findings and the version-pinned Agent handoff remain outstanding.
0.20.2 approvals and its per-timed-run state waiver do not transfer automatically.
