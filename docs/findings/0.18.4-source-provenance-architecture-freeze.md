## Audit and explicit correctness decision

The [invariant matrix](../design-source-provenance-architecture-freeze-0.18.4.md)
maps the 0.18.0–0.18.3 contracts to focused existing tests and the new combined
`test_source_provenance_architecture_freeze.py` suite. Existing 0.17.7/context
freeze tests remain unchanged and execute in the full gate; tests were not copied
solely to increase counts.

The stale-prose issue was reproduced through public APIs: exact slot state was
`WITHDRAWN` and readmission was deferred, yet current context rendered the later
assertion. Existing tests checked durable deferral without checking that context.
This is a correctness defect and cannot be certified as a production Agent
invariant. The user explicitly approved the
[separate corrective design](../design-withdrawn-readmission-context-correction.md)
before retrieval code changed.

The approved fix extends the existing stale projection to later exact structured
assertions matching a known closed claim. It reuses canonical identity parsing,
exact revision batch reads and the existing fragment filter. It preserves
separable unrelated content and historical factual reads; it changes no persisted
episodes, semantic revisions, admission/withdrawal decisions or counters. No
authority/trust signal is added to ranking. This intended eligibility/rendering
correction is not described as unchanged cognitive output for affected queries.

## Temporal and storage clarifications

Exact slot historical `as_of` masks present-store latest-source comparisons.
Prepared-context provenance retains the existing present-store comparison; its
API does not offer historical latest-pointer reconstruction. Missing exact evidence
alone may coexist with a provable `KNOWN` slot and incomplete coverage; unsupported
temporal/legacy reconstruction instead becomes `INDETERMINATE`.

Canonical slot prefixes use logical identities, not UUIDs. Context provenance
order and unrelated arbitrary-UUID retrieval behavior are not redefined. Optional
inspection remains separate from mandatory store protocols; no migration or
new dependency was added.

## Retained limitations / deferred work

- Independence stays `UNKNOWN`; no trust/truth score or automatic abstention policy.
- No durable deferred-decision ledger or complete bitemporal reconstruction.
- Finite scalar exact-slot qualifiers; no atomic cross-store snapshot guarantee.
- Output caps do not bound all underlying rows, JSON bytes or engine pages scanned.
- Arbitrary-UUID retrieval determinism is not promised; controlled comparisons remain necessary.
- The correction requires available exact structured evidence and recognizable
  claim identity. It does not infer claims from arbitrary unstructured prose,
  restore missing metadata, or certify every custom extractor/legacy representation.
- SQLite/local persistence remains 0.19.x; production Agent contract remains 0.20.0.
- Any frozen-output exception or additional correctness issue must be recorded
  explicitly before completing the freeze.
