as 0.20.1. A wheel and source distribution built from that checkout passed `twine check`. The
wheel was installed without dependencies in an isolated CPython 3.11.15
virtual environment; the smoke check found SQLite migrations through
`008_history_order` and PostgreSQL `015_history_order`, verified that
SQLAlchemy was absent, and confirmed retrieval identity and score after a
fresh-process SQLite restart.

- wheel SHA-256 `3ac5afc09cf297f7adfe49193a787c392a028b48fc5a1a1a885569a572738b17`

identity, installation from the final sdist, cross-version compatibility,
