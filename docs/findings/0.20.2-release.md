# Core 0.20.2 hardening gate status

**In progress. No release candidate, tag or publication is approved.** The
working package now identifies as 0.20.2, but is not frozen; the source evidence
below is not a substitute for validating an exact frozen 0.20.2 candidate and its artifacts.

- Retrieval timing: three independent local memory and SQLite baseline and
  0.20.2 working-source runs at each required size met the synthetic targets;
  recorded outputs and selected state match. Separate untimed cognitive-state
  audits pass at all three sizes on both backends, with documented coverage
  limits. Complete per-timed-run state comparison and frozen-candidate timing
  remain open. The user confirmed the physical reference host.
  See [repeatability](0.20.2-performance-repeatability.md).
- Context: the five operations have exploratory measurements at 100, 250 and
  1,000 observations. Three independent 100-sample narrow-query preparations
  per backend met the proposed target, with matching rendered outputs. The full
  variation matrix, output validation and approval of the proposed Agent-facing
  target remain open. See [context preparation](0.20.2-context-preparation.md).
- History and snapshots: targeted missing/incompatible history, interleavings,
  tenant clear, and rollback tests pass across the documented backends. They do
  not establish universal history coverage or transactional concurrent reads.
  See [historical integrity](0.20.2-historical-integrity.md) and
  [storage findings](0.20.2-storage-upgrade-and-snapshots.md).
- Upgrades: source-based 0.19.5 and 0.19.6 SQLite and PostgreSQL migrations
  were exercised, including injected migration failure and retained cognitive
  state, corrections and withdrawals, including retained revision snapshots.
  Published SQLite and PostgreSQL wheels also upgraded under a provisional
  installed 0.20.2 wheel; final candidate-distribution checks and additional history variants
  remain open.
- Snapshot growth: repeated tenant-wide processing amplified stored history in
  the synthetic probe. Agent impact, retention and the disposition of this
  measured limitation require review before release.
- Project workload: scoped evidence and a multi-session lifecycle covering
  knowledge time, corrections and withdrawal pass across the tested backends.
  Unscoped relevance and the broader workload assessment remain unresolved. See
  [project findings](0.20.2-project-workload.md).
- Bench: 0.20.2 version gates and explicit v2 fixture selection are in progress.
  The four-backend baseline and working-tree parity checks pass. The working-tree
  raw frozen comparison fails with unapproved mismatches matching the earlier
  0.20.1 run fingerprints; 0.20.2 still needs an exact candidate comparison
  and candidate-specific review.
- Compatibility: local source checks ran on Python 3.11–3.15, with separate
  PostgreSQL-marked checks. Final candidate artifacts and hosted platforms are
  not yet validated. See [Python findings](0.20.2-python-compatibility.md)
  and the [artifact probe](0.20.2-artifact-probe.md).

Do not tag or publish until the design's mandatory gates and remaining issues
are resolved and separate release approval is obtained.
