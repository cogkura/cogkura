the release tags, prior wheels and upgrade-admin URL required by the new
upgrade tests. The job has been updated to fetch full Git history, download and
SHA-256-verify the published wheels, build the candidate wheel, and supply a
disposable-database admin URL. The download helper passed its local failure

job scope, where it is unavailable. After that was fixed, five Windows jobs
failed snapshot-growth script tests because its temporary SQLite connections
were left open. The script now closes those connections explicitly and tests
expose subprocess errors; the resulting `64f85f7` hosted matrix passed all 25
jobs. No runtime package source changed between `442b5d2` and this candidate.
