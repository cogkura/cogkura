# 0.18.1 source authority findings

**Decision:** admit one explicitly authorised fact as an ordinary semantic memory, and leave every other consolidation and retrieval rule on the `0.18.0` contract.

The application asserts authority. Cogkura checks that the declaration is well formed and bound to the episode's current, non-deleted observation revision. It does not decide that the statement is true, and it does not make the memory easier to retrieve.

Observed limits:

- A metadata-only resubmit does not open a new observation revision. The authority declaration has to arrive with a source-version, content, deletion, or encoding-context change, or ingest keeps the previous revision.
- Fact extraction still reads the current observation. The authority check is the only path that requires the cited revision's own `semantic_facts`. An unresolved or mismatched revision fails closed.
- Promotion provenance lives in semantic memory metadata. `semantic_claim_revisions` has no metadata column, so historical revision rows do not carry a separate copy of the basis.
- The original promotion block is kept when later episodes reinforce the same claim. Withdrawing authority on a newer source revision does not delete or supersede the memory. That correction lifecycle is `0.18.2`.
- Competing single-support authority claims are deferred rather than reconciled. Recurrence-qualified claims still use the existing reconciler.
- Confidence, importance, activation, forgetting, interference, and inhibition are unchanged. An authority memory with one supporting episode scores like any other one-episode semantic memory.
- `MemoryContext.render()` does not explain the promotion route. Callers inspect `metadata["semantic"]["promotion"]` or `MemoryProvenance.promotion`.
- CogkuraBench `0.3.8` still pins Core below `0.18.0`, and its backend forces `minimum_supporting_episodes=1`. This release does not retune retrieval and does not claim a bench run. A later bench fixture should add the authority cases without changing existing datasets.

`tests/test_018_1_source_authority.py` is the controlled evaluation for this release. It covers single authoritative facts, ordinary recurrence, isolation, revision mismatch, malformed declarations, competing authority, coexistence, idempotency, and recall parity with single-episode consolidation.
