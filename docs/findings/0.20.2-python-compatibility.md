# 0.20.2 Python compatibility: source checks

**Status: exploratory; the exact candidate artifact matrix remains open.**
The full matrix used the working source checkout when it reported Core 0.20.1;
it does not verify a 0.20.2 release candidate or package artifact.
PostgreSQL-dependent tests were skipped when no server was configured.

On macOS, CPython 3.11.15 with SQLite 3.53.1 passed the local Core suite with
1,053 passed and 61 skipped. CPython 3.15.2 with SQLite 3.53.1 likewise passed
1,053 tests with 61 skipped.

A separate Homebrew CPython 3.13.0 interpreter linked SQLite 3.50.1. Its
partial suite encountered 11 SQLite-dependent failures and was interrupted
after 380 passes and 3 skips; the exceptions identify Core's documented
rejection of SQLite versions affected by the WAL-reset vulnerability. This is
not a passing 3.13 matrix entry and is retained here rather than discarded.
A managed CPython 3.13.14 interpreter linked to SQLite 3.53.1 was prepared for
a separate full run. The remaining local results will be added after validation.

The full local suite subsequently passed on each of the following managed
interpreters, all linked to SQLite 3.53.1:

| CPython | Passed | Skipped |
| --- | ---: | ---: |
| 3.12.16 | 1,053 | 61 |
| 3.13.14 | 1,053 | 61 |
| 3.14.10 | 1,053 | 61 |

Together with the 3.11.15 and 3.15.2 results above, this covers source-suite
execution on all five requested Python minors in the local macOS environment.
It does not replace candidate wheel/sdist installation, PostgreSQL integration
across the matrix, hosted operating-system checks or the final candidate gate.

The PostgreSQL-marked suite was also run on local PostgreSQL 14.18 with an
isolated database per interpreter. CPython 3.11.15, 3.12.16, 3.13.14, 3.14.10
and 3.15.2 each passed 55 PostgreSQL-marked tests with six skipped. The
six skips include checks requiring additional source or privileged database
configuration. These results cover the current source checkout and the tested
local PostgreSQL environment, not a final candidate artifact or other hosted
platforms. The disposable cluster and its databases were removed afterward.

The full source-suite runs predate the later snapshot-reinforcement probe and
its test. Both probe tests subsequently passed on Python 3.12–3.15. Rerun the
complete matrix after the candidate is frozen to validate the final tree.

The later 0.20.2 working tree was also tested locally on all five Python
minors after the expanded context harness and legacy transition-upgrade tests.
Each full source-suite run passed 1,064 tests with 66 skips. For 3.12–3.15,
the provisional 0.20.2 wheel supplied installed distribution metadata and
`PYTHONPATH` selected the working source; the tests are therefore source-suite
evidence, not a final wheel test. Separate clean, dependency-free wheel smoke
checks passed on each minor as described in the
[artifact probe](0.20.2-artifact-probe.md). These remain local macOS results.
