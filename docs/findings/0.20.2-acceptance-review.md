`MISSING_KNOWLEDGE` is an answerability warning even if memories are rendered,
per the user's recommendation. The existing experimental Agent exposes flags
but has not yet implemented and validated that warning; this is an Agent
follow-up, not a claim about existing Agent behavior.

The evidence does not prove all possible historical states, concurrent read
interleavings, context configurations, retention outcomes or application
workloads. The explicit waiver is limited to Core 0.20.2. The user subsequently
approved the exact successor and authorized tagging and publication. Tag
`v0.20.2` points to that candidate; the [GitHub release](https://github.com/cogkura/cogkura/releases/tag/v0.20.2)
and [PyPI package](https://pypi.org/project/cogkura/0.20.2/) are published.

The candidate archive predates its final review. The later documentation on
`main` records the completed review and waiver, and release notes should link
to that final evidence. The `fb72911` frozen-gate approval was independently
obtained; it was not transferred from `64f85f7`.
