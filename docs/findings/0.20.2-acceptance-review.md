`MISSING_KNOWLEDGE` is an answerability warning even if memories are rendered,
per the user's recommendation. The existing experimental Agent exposes flags
but has not yet implemented and validated that warning; this is an Agent
follow-up, not a claim about existing Agent behavior.

The evidence does not prove all possible historical states, concurrent read
interleavings, context configurations, retention outcomes or application
workloads. The explicit waiver is limited to Core 0.20.2. No tag or publication
is authorized by this review; final release-owner review and separate approval
for the actual release remain necessary.

The candidate archive predates the final review: its changelog and release
findings still describe 0.20.2 validation as in progress. The later documentation
on `main` records the completed review and waiver. Before publication, release
notes should accurately link to the final evidence, or a successor candidate
must be prepared and receive the candidate-specific verification and approvals
required by the design. Do not silently transfer the `64f85f7` frozen-gate
approval to another commit.
