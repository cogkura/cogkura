# Cogkura Core 0.20.1 release

Core 0.20.1 is published at [GitHub](https://github.com/cogkura/cogkura/releases/tag/v0.20.1)
and [PyPI](https://pypi.org/project/cogkura/0.20.1/). The annotated tag resolves
to approved commit `4c53eb6a5f77cb9c275c7b39529f08fac7e809b1`. Its exact-tag
[Core CI matrix](https://github.com/cogkura/cogkura/actions/runs/44959819386)
passed all 25 jobs, and the [publication workflow](https://github.com/cogkura/cogkura/actions/runs/44960151368)
completed its build and PyPI publish jobs.

The independent [reviewed frozen gate](https://github.com/cogkura/cogkura-bench/blob/31da167/docs/findings/core-0201-4c53eb6-frozen-gate-resolution.md)
passed with the explicitly approved exact candidate-specific differences; the
original gold and raw failure remain preserved. The [backend and artifact checks](https://github.com/cogkura/cogkura-bench/blob/31da167/docs/findings/core-0201-4c53eb6-release-checks.md)
include exact in-memory, SQLite, reopened SQLite and PostgreSQL parity. Source
history v2 passed 191/191 on memory and PostgreSQL.

PyPI metadata and the publication workflow artifacts agree on both file hashes:

- `cogkura-0.20.1-py3-none-any.whl`: `7ad25f72bcfee3ff743533d72ae2c600f229a1818b115ce4acb0bc17507d44a9`
- `cogkura-0.20.1.tar.gz`: `1299a03fe8bfafcb43155186ca6377086833b3ee708c71938f8331b6bfd6b8d3`

The published wheel hash also matches the pre-publication wheel, and its 87
Core files match the tagged source byte-for-byte. The published sdist archive
hash differs from the locally built archive; all 520 contained file paths and
file contents match. A clean dependency-free installation from PyPI passed
version and module identity, SQLite migration, recall and fresh-process restart.

The selected-Mac p95 at 1,000 observations was 1.191 s in memory and 1.741 s
on SQLite. This is a synthetic single-environment result, not a production
latency guarantee. Historical reconstruction still has limits for legacy or
custom stores, missing snapshots and concurrent writes. The tagged source's
changelog listed 0.20.1 under Unreleased; this post-release documentation
updates the main-branch changelog without changing the tag or published files.
