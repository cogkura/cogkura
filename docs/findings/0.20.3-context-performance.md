# 0.20.3 context-preparation reference evidence

**Status: target and independent-audit protocol approved; exact-candidate review
remains open.** On 25 November 2026 the release owner approved warm p95 below
2.5 seconds separately for memory and SQLite for the design's fixed
1,000-observation fixture, and separate timing and cognitive-state audits.

The six existing 0.20.2 preparation-only runs used the confirmed 2018 Mac,
Python 3.11.15 and macOS 15.8.1, three independent processes per backend and
100 fixed-state preparations per process. Their memory p95s were 1.354, 1.359
and 1.324 seconds; SQLite p95s were 1.843, 1.796 and 1.812 seconds. The prior
working-memory snapshot was prepared before timing, with pool 50, budget 2,048,
structured query context and learning enabled. All repeated contexts matched
within each process and their rendered hashes matched across backends. See the
[original findings and raw reports](0.20.2-context-preparation.md).

`6dda332c0ad3627c92a251b2b340b8173cadbca92cf4e12354300884a9fe51ea`.
