## Underspecification margin

**Frozen default:** `context_underspecified_margin=0.0` (exact ties only).

The knob affects classification on inspect and metamemory only. It does not change activation or ranking. Increase only when product telemetry shows near-tie false negatives; document any non-zero value as engineering calibration, not a cognitive-science constant.
