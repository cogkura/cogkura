# Episode-history slice: local validation

Status: partial implementation and diagnostic evidence, not release approval.
The tested Core commit is `a6ddb1c8dc4dffbcfe6cba7eeed9cf28dca355a9`; the
reference checkout was `b30433c9577fe2493072e442b0f4ea307f342fcf`. The current
episode slice does not reconstruct semantically linked or currently inactive
episodes, semantic aggregates, or semantic relation history. See the
[implementation design](0.20.1-historical-reconstruction-design.md).

The Core suite on the 2018 Mac passed 1,065 tests with five skipped against an
isolated fresh PostgreSQL database. Ruff, format and mypy passed. Focused tests
cover in-memory, SQLite and PostgreSQL episode history; SQLite restart,
transaction rollback and upgrade without fabricated history; equal and
backdated writes; and tenant isolation. No candidate performance measurements
were made, and this is not an official-origin or hosted-CI validation.

## Frozen diagnostics

Bench `7373d5ff2d00b10a9dd260e5fc3869b031850c34` ran on the same Mac using
CPython 3.11.15, SQLite 3.53.1, seed 183 and `PYTHONHASHSEED=0`. The source
history v2 fixture passed 191/191 on the candidate; PostgreSQL source parity
and diagnostic parity passed. The strict frozen gate failed.

For a local paired diagnostic, the candidate and reference source checkouts
were selected through `PYTHONPATH` in separate processes, using fresh separate
PostgreSQL databases. The reference checkout was clean at `b30433c` and an
independent import check confirmed its module path. Distribution metadata in
the reference report still identifies the candidate's editable installation;
therefore these reports do **not** establish official install provenance and
must not be treated as formal release evidence.

Across the paired reports, all aggregate non-latency metrics and recorded-use
signatures match. Query-detail hashes were checked against each report before
comparing fields. Exactly three queries differ: `ac-q-c17` (six fields),
`ac-q-hist-at-withdraw` (five), and `ac-q-hist-before-withdraw` (eight).
These reproduce the earlier correction-history score and `supersedes` relation
differences. The user's prior decision did not approve those differences, and
this comparison neither approves them nor changes the frozen reference.
