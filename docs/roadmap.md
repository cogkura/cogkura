# Roadmap

## 0.0.x - Foundation

- package structure and typed API;
- memory event models;
- in-memory storage backend;
- deterministic recall baseline;
- tests and documentation;
- PyPI publishing workflow.

## 0.1 - Episodic memory

- richer event encoding;
- temporal context handling;
- source and entity relationship links;
- importance and salience scoring.

## 0.2 - Semantic consolidation

- episodic clustering;
- concept extraction;
- semantic memory construction;
- conflict and duplicate handling.

## 0.3 - Cognitive retrieval

- spreading activation;
- associative scoring;
- forgetting curves;
- attention and goal filtering;
- working-memory selection.

## Later

- SQLite and PostgreSQL adapters;
- graph-oriented storage options;
- embedding-provider interfaces;
- LLM-provider interfaces;
- MCP and agent-framework integrations;
- benchmark suites;
- enterprise-oriented extensions.
